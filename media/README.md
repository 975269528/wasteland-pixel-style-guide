# 效果预览目录

这些画面来自代码 `adbd259` 的 Windows Runtime 实际 GPU 捕获。所有 PNG 保留原始 `1280×720` 尺寸，可直接打开看完整场景；没有对角色、装备或背景进行后期拼接。

| 文件 | 观察重点 |
| --- | --- |
| `scene.png` | 草土、细干树群、上沿岩壁、马与骑手、独立阴影、装备栏 |
| `ordinary-walk.png` | 普通行走的低抬脚、较直支撑腿、上下身接缝 |
| `ordinary-run.png` | 普通跑步的更大摆幅、回摆收腿与髋升降 |
| `combat-back.png` | 朝目标瞄准，同时按相反方向后退 |
| `combat-strafe.png` | 面向与移动分开后的侧移步态 |
| `foot-machete.png` | 砍刀形体、刀背和切刃辨识、步行近战 |
| `mounted-machete.png` | 骑乘砍刀专用下劈，骑手与马分层 |
| `mounted-axe.png` | 骑乘短斧的下劈高度和接触反馈 |
| `mounted-spear.png` | 骑乘长矛双手握持与下刺 |
| `mounted-gun.png` | 马行进时的侧向骑射，坐位升降同步手锚 |
| `animation-preview.gif` | 普通走跑、战斗后退侧移、骑射及三种骑乘近战的连续运动 |

GIF 使用 257 张本次采集帧中的 213 张，约 10.79 秒。片段内保留采集时间间隔，没有补帧；片段之间删去等待和重复部分。GIF 的 256 色上限与 10 毫秒计时粒度会影响颜色和个别帧的时间表达，材质颜色优先参考 PNG。

独立截图的名字描述采集场景，不保证截图正好是代码标记中的动作接触帧。离屏纹理呈现有延迟，应结合连续帧、沙袋闪色和命中计数观察实际接触。

`media-provenance.json` 记录源序列索引、导出时序限制和版本，便于后续替换预览时核对。这里的采集帧率不代表手机设备能够稳定达到的帧率。
